# KAY production assets

| File | Use |
|---|---|
| `kay-hero-still.webp` | **Current homepage hero** (static 2D, preferred) |
| `kay-hero-still.png` | Transparent fallback for the 2D hero still |
| `kay-web.glb` | Archived hero WebGL model — preserved, not loaded on the homepage |
| `anthropomorphic+fox+3d+model(2).glb` | Original preserved source |
| `kay-web.webp` / `kay-seo.webp` / `kay-analytics.webp` / `kay-ai.webp` / `kay-cta.webp` | Section stills |

KAY 3D is archived for future reactivation. While `kay3dArchived` is true, the homepage must not request `kay-web.glb` or initialize WebGL. Do not delete or retouch the GLB.
