# SALKAY

Premium website for SALKAY — a Turkish digital studio focused on web design, custom development, and measurable growth.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- React 19

Primary language is Turkish. Dictionary architecture is ready for DE and EN.

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Notes

Do not invent client counts, testimonials, awards, addresses, or performance claims. Project cards on the homepage are clearly marked placeholders.
